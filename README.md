# iTab Local · 新标签页

基于当前提供的 iTab 2.3.13 发布包分析后，新建的独立 Manifest V3 扩展工程。聚焦主页、网站图标、打开方式、搜索栏、时间日期、主题壁纸、布局、主页组件和 Google Drive 备份。

## 直接使用

已经生成 `dist` 目录和 `release/itab-local-1.0.1.zip`，不需要安装 Node.js 就能加载构建好的扩展。

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 打开“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择本项目下的 **`dist`** 目录。如果使用 ZIP，先解压，再选择包含 `manifest.json` 的目录。
4. 打开新标签页，确认使用 iTab Local 作为新标签页。

当前目录位置：

```text
C:\Users\unbel\Downloads\iTab新标签页\itab-replica\dist
```

Google 备份需要在 Chrome 中配置自己的 OAuth 客户端 ID，操作步骤见 [Google备份配置.md](docs/Google备份配置.md)。未配置时，本地主页和 JSON 备份正常可用。

可添加的组件：天气、日历、热搜榜、倒数日、备忘录、待办、下班倒计时、电影卡片、计算器、番茄钟、饮水记录、壁纸入口，共 12 类本地组件。

本地 PDF / AiPPT 功能与默认入口已移除，不包含旧主页迁移逻辑。计算器使用安全算式解析，不执行字符串脚本。

右键空白处可打开主页菜单；右键图标可编辑、移动、调整尺寸或删除。按 `/` 聚焦搜索，按 `Esc` 关闭菜单/弹窗。

## 本地开发

需要 Node.js 20 或更新版本，Windows PowerShell：

```powershell
Set-Location -LiteralPath 'C:\Users\unbel\Downloads\iTab新标签页\itab-replica'
npm install
npm run dev
```

访问 [http://127.0.0.1:4173](http://127.0.0.1:4173)。不要双击 `index.html` 使用 `file://` 打开，因为主页通过 ES Modules 和资源请求加载数据。

```powershell
npm run check
npm test
npm run build
```

- `check`：检查 JavaScript 语法、扩展入口、默认数据和本地图片路径。
- `test`：运行 19 项数据、Google 请求契约、日期、算式、榜单解析、原版目录与入口备份检查。
- `build`：构建可直接加载的 `dist`；有 `google.config.json` 时自动写入 OAuth 配置。
- `configure:google`：配置你自己的 Google OAuth 客户端 ID。

项目使用原生 ES Modules，无第三方 npm 运行依赖；现成的 `dist` 可以独立使用。原版在线组件在第三方 iframe 页面中运行。

一次性资源提取脚本 `prepare-assets.mjs` / `prepare-seed.mjs` 仅用于分析原包，不属于正常开发或构建必需步骤。复制此项目到别的目录后仍可独立构建。

## 数据与网络

- 设置、网站和组件内容保存在当前浏览器/扩展的 IndexedDB。网页预览与扩展使用不同的数据空间。
- 内置壁纸、字体、图标和主体功能离线可用。用户提供的网络图片、天气和热榜需要联网。
- 天气使用 Open-Meteo；百度热榜读取官方公开页面；科技热榜使用 Hacker News / Algolia。
- Google Drive 只申请隐藏应用数据目录权限，不访问普通网盘文件；令牌不写入备份。
- 本地图片最大 8 MB；JSON 备份最大 25 MB。本机快照保留最近五个。
- 多标签页空闲时自动加载其他标签页的更新；编辑弹窗中会提示其他页面有更新，避免突然覆盖正在输入的内容。

## 与原版的差异

主页的基准尺寸、原默认壁纸、网站图标、网格位置和设置抽屉已对照原版还原，但本项目**不是原版全部在线服务和所有视觉细节的完全等价复制**。

- Google Drive 替代原 iTab 账号备份，需要完成 [OAuth 配置](docs/Google备份配置.md)，本次没有使用真实 Google 账号完成授权。
- 原账号、会员、支付和推广不接入。本地 PDF 与 AiPPT 已移除，原版仓库中的条目保留。
- 微博/抖音热榜提供官方页面入口；百度和科技热榜直接展示实时列表。
- 电影日历是可编辑的本地电影卡片，不是原每日推荐服务；天气不包含原版完整空气质量详情。
- 下班倒计时不包含原版工资/发薪计算。
- 原版全局悬浮搜索、商城和其他非主页范围功能未纳入。
