# NewTab · 新标签页（2.1.0）

基于本次提供的原版 2.3.13 发布包创建的独立 Manifest V3 扩展。保留主页、网站图标、打开方式、搜索栏、时间日期、主题壁纸、布局，以及 Google Drive / JSON 备份。

## 安装

1. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
2. 启用开发者模式，点击“加载已解压的扩展程序”。
3. 选择本项目的 **dist** 目录；使用 ZIP 时先解压，选择包含 manifest.json 的目录。
4. 打开新标签页。

发行包：release/NewTab-2.1.0.zip。源码包：release/NewTab-source-2.1.0.zip。

Windows 发行打包：构建后执行 `powershell -ExecutionPolicy Bypass -File scripts/package.ps1`，生成安装 ZIP、源码 ZIP 和 `release/SHA256.txt`。源码包使用白名单，不包含测试 profile、构建中间文件、node_modules 或本机 Google 配置。

## 原版界面

设置已接入原包的 7 个 Vue 页面和对应控件：打开方式、搜索栏、图标、时间/日期、主题/壁纸、布局、侧边栏。抽屉使用原版 450px 结构，字体使用原包内可用的 WOFF 文件，主页常用操作图标使用原版 Tabler 图形。内置组件弹窗直接显示原版窗口，文件夹、菜单和宿主表单采用原版视觉规范。

图标编辑和自定义添加直接使用本次原包的 `IconEdit` / `CustomAdd`：原版 740px 弹窗、网站图标获取、当前图片与文字图标切换、调色板、自定义颜色、图片上传，以及裁剪、旋转和缩放。新增网址支持“保存并继续”。PNG/JPEG/WebP/GIF 经过原版裁剪生成 PNG，SVG 保留矢量内容；上传图片直接保存在本地，进入当前 JSON / Google 备份。主页与文件夹内的网站图标采用原版图片适配、文字缩放、透明背景和交互阴影规则。固定使用当前 2.3.13 原包，无历史版本迁移或兼容分支。

Google / JSON 备份、网址和分组编辑继续连接当前本地数据。原版账号、会员、支付、云同步，以及全局网页注入搜索和自动壁纸任务不接入当前工程。更多细节见 [原版界面替换](docs/原版界面替换.md)。

## 组件

- 只使用原版组件，已删除全部 12 类本地重写组件及其入口、业务、样式和专属接口。
- 29 项内置组件使用原版 Vue 卡片、弹窗及业务实现；18 项在线组件打开原站页面。
- “下一个假期”在主页使用原版动态卡片，显示假期日期和剩余天数，点击后打开原站详情；已有组件刷新即可恢复，新添加时默认使用 `4x2` 宽卡片。
- 原版仓库先经过固定允许清单校验，当前可添加 47 项。未知组件不自动放行；网络不可达时展示随包的 29 项内置组件。
- PDF 转换、AiPPT 不在允许清单中，随包运行代码也已移除。旧 videoConvert 入口已删除，保留当前 mediaBox 媒体工具箱。
- 删除股票图片导入、原版壁纸上传/收藏、便签图片上传、原版账号/登录/会员/充值/云同步及统计身份逻辑。免费股票行情、公开壁纸、便签富文本编辑等保留。
- 主页时钟和日期属于主页功能，继续保留。

内置组件数据由当前宿主直接保存到主页状态，包含便签全文、待办及其完成状态、计时器、组件配置和缓存。没有 localStorage 覆盖、Chrome API 模拟、localforage / Dexie 仿真层。

在线组件由跨域原站维护；它们内部的数据不进入本项目备份，本项目不读取或管理原站账号。仅放行本次审核时主体功能可匿名使用的原版在线入口；外部服务后续收费策略和可用性无法由本项目固定。详情见 [组件清单与屏蔽依据](docs/组件清单与屏蔽依据.md)。

## 数据与备份

当前持久化数据格式为 schemaVersion 2，数据库为 itab-local-v2。支持当前项目的 v2 JSON / Google 备份，以及原版导出的 `.itabdata` / JSON 备份；原版备份在导入时转换为当前格式。不导入原版账号、令牌和云同步身份，不迁移本项目的 v1 数据。

### 导入原版备份

1. 打开主页侧栏的“备份”，点击“导入备份数据”。
2. 选择原版导出的 `.itabdata` 文件（最多 25 MB）。
3. 查看识别到的类别、数量和兼容提示，点击“确认”。当前主页会先保存为本机历史节点，可随时从备份页恢复。

支持分组、网站、文字图标、文件夹、当前允许的内置/在线组件及其配置、主页外观、搜索引擎、壁纸链接、热搜列表、便签全文、待办（含已完成项目及分组）和自选股。原版横向 `2x4` 组件会转换为当前 `4x2`，网站查询参数保留，图标按原有顺序和尺寸在当前网格重新排列。

原版允许按类别导出；只替换文件中包含的类别，缺失类别保留当前数据，明确导出的空列表会清空对应类别。当前未支持的组件会在确认前列出并跳过；仅包含本机引用、没有图片内容的壁纸会提示并保留当前壁纸。原版独有的账号同步、全局搜索、自动壁纸等功能不随备份启用。导入完成后仍可通过本项目 JSON 或 Google Drive 备份保存转换后的数据。

Google Drive 使用 drive.appdata 范围。需要自己的 OAuth 客户端 ID，配置见 [Google 备份配置](docs/Google备份配置.md)。尚未配置客户端 ID 时，JSON 导出、导入和本机快照可用。

左上角头像显示扩展中已连接的 Google 账号头像，点击仍进入备份页面。打开新标签页时静默读取账号，连接、备份或断开授权后同步更新已打开页面的头像；未授权、离线或头像加载失败时显示默认头像。账号名称和头像使用现有 Drive 授权读取，不增加 OAuth 权限，也不写入主页备份。

完成首次 Google 授权后，新标签页会自动恢复 Drive 连接和云端备份列表，无需每次点击“连接 Google”。自动连接只读取列表，上传和恢复仍由你手动操作；首次授权或授权失效时提供手动连接入口。主动“断开本机授权”会记住关闭自动连接的选择，直到再次手动连接。

## 开发与检查

要求 Node.js 20 或更新版本，在本项目目录运行：

~~~powershell
npm install
npm run dev
npm test
npm run check
npm run build
~~~

开发地址为 http://127.0.0.1:4173。常规构建仅使用本工程文件，不依赖上级原包。scripts/prepare-native.mjs 是重新导入本次指定原包的开发工具，包含版本校验、功能裁剪、依赖构建和无引用资源清理；没有运行时跨版本兼容代码。
