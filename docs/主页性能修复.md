# 主页性能修复验证（2026-09-28）

本次修复限定为编辑模式重载组件，以及原版共享日期时钟逐帧检查时间。

## 改动

- `src/app.js`：抽出顶部操作栏渲染；编辑开关只修改现有卡片的 `editing` 类和顶部按钮，不再调用全页 `render()`。保留原 iframe、Document、Window、组件状态和搜索输入。
- `original/chunks/chunk-LEVEZLTX.js`：共享日期时钟改用对齐下一整秒的单次定时器，每次读取系统实际时间。保留初次立即更新、后台暂停、恢复立即校时、跨日日期更新和最后一个订阅卸载后的清理。
- `scripts/refine-native.mjs`：重新导入指定原包时应用同样修复，并校验原时钟结构。其他用于数值过渡等真实动画的 `requestAnimationFrame` 不变。

样式、动画时长、模糊、壁纸和组件内容均未改动。

## 结果

浏览器验证使用独立 Chrome 测试配置、1440 × 900 窗口和默认 9 个卡片。不是用户日常 Chrome 的性能测量；未推断实际帧率或整页 CPU 降幅。

| 检查 | 修改前 | 修改后 |
| --- | --- | --- |
| 进入编辑时原卡片重载 | 9 个 | 0 个 |
| 连续 3 轮进入、退出编辑 | 全页渲染会销毁卡片 | 9 个 iframe、Document、Window 全部保留，导航次数为 0 |
| 4 个日期相关卡片，5 秒逐帧回调合计 | 2,876 次（每卡片 719 次） | 0 次 |
| 日期共享时钟节奏 | 按显示刷新率检查 | 按整秒更新；确定性测试 5 秒执行 5 次 |

浏览器测量中各日期卡片记录到 6 次定时回调，包含组件初始化定时任务；该计数不等同于全部来自日期时钟。确定性测试直接执行随包时钟函数，单独验证其每秒节奏。

编辑时组件仍禁用指针事件以便拖动，退出后恢复交互。搜索输入、便签内容和卡片右键菜单通过检查，期间无未捕获 JavaScript 异常。截图保存在 `output/playwright/perf-after.png`。
