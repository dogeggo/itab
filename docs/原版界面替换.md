# 原版界面替换（2.1.0）

基准：用户提供的原版 2.3.13 发布包。实施日期：2026-09-27。

## 实际替换范围

| 界面 | 当前实现 |
| --- | --- |
| 设置抽屉 | 原版 450px 右侧结构，140px 导航与 310px 内容；窄屏铺满；遮罩透明，实时预览主页 |
| 打开方式、搜索栏、图标、时间/日期、主题/壁纸、布局、侧边栏 | 直接使用原包 Vue 组件的渲染函数和业务控件；使用原版 Element Plus、滑块、开关、单选预览、调色板、字体下拉菜单 |
| 字体 | 随包 WOFF，正文采用原版系统字体栈；原版 Arial Rounded 只用于指定的时间字体，不覆盖正文 Arial |
| 主页操作图标 | 提取原包 Tabler SVG 数据，覆盖侧栏和常用菜单操作；不通过运行时网络获取图标 |
| 原版内置组件窗口 | 原版窗口直接覆盖主页；删除宿主重复的标题栏、边框和留白，保留原版关闭/新窗口/最大化交互 |
| 图标编辑与自定义添加 | 直接使用原包 IconEdit / CustomAdd、Element Plus 调色板与 VueCropper；原版 740px 窗口，支持获取图标、文字图标、上传、裁剪、旋转、缩放和保存并继续 |
| 网站图标显示 | 原版 contain/cover 规则与本地图标来源清单，22px 文字及按实际宽度缩放，透明背景、原版阴影和按下效果；文件夹内的网站使用同一渲染器 |
| 文件夹、右键菜单、分组表单、组件目录 | 采用原版圆角、磨砂、字体、尺寸和 Windows 关闭按钮规范，业务继续由当前宿主维护 |
| Google / JSON 备份、关于、重置 | 保留当前项目功能，放入统一设置抽屉 |

主页网格、分组、网址编辑、搜索执行、当前数据保存与备份仍由宿主负责。这里的“原版界面”不表示恢复原版账号后台，也不表示所有宿主逻辑都替换成原包的主页脚本。

图标编辑的 UI 与图片裁剪直接复用原版；数据写入当前主页结构。编辑保留原来的分组/文件夹位置，移动仍使用右键菜单。获取图标调用原版公开网站信息接口，接口不可用时可继续使用文字和上传；较早返回的查询不会覆盖已修改的网址。上传图片保存为本地 data URL，临时裁剪地址在关闭窗口时释放。关闭未保存的弹窗会丢弃草稿。

图标编辑与组件窗口共用主页的 5px 背景虚化和遮罩。编辑器 iframe 的实际 `color-scheme` 与宿主保持一致，并在加载原版控件前应用主题，避免原版 `color-scheme: none !important` 使深色主页背后的透明画布显示白底。裁剪弹窗仍单独遮暗下方编辑器。深色验收包含整页截图、iframe 配色方案和宿主虚化检查。

## 数据与资源

- `original/appearance/components.js`：7 页原版 UI 的独立构建产物，保留原版控件；不包含账号、云同步、上传到原站、localStorage 或浏览器 API 模拟层。
- `original/appearance/provenance.json`：输入版本、原组件文件、原 CSS、依赖文件清单。
- `original/appearance/host.html`、`host.js`：隔离原版全局 CSS，通过受当前 iframe 与状态对象约束的会话访问设置。
- `src/appearance-model.js`：转换原版 `opactiy`、`iconSize`、日期 inline/none、数字开关等字段；保存前继续经过当前 schemaVersion 2 校验。
- `original/icon-editor/`：固定原包的编辑、添加、裁剪渲染函数和样式，以及本地资源的图片适配来源清单；独立窗口隔离全局 CSS。
- `src/icon-editor.js`、`src/site-icon.js`：当前图标会话、本地图片保存、网站信息获取和统一网站图标渲染；没有账号、云上传、浏览器存储模拟或旧版数据分支。
- 新增百分比网格宽度、侧栏记住分组/滚轮切换、原包本地字体。这些设置进入当前 JSON / Google 备份；已有 v2 设置无需重置。
- 调整设置仅更新主页外观，不重建正在运行的小组件。关闭组件先等待保存，再移除 iframe，避免番茄钟或编辑器先卸载导致数据丢失。
- 原包没有随附的 SFUI、BungeeHairline 不列为本地字体选项。旧 v2 的 Oswald 设置仍能使用工程已有的字体文件。

没有接入原版登录、会员、支付、云同步、全局网页注入搜索、自动壁纸任务。主题页“更换壁纸”打开现有原版壁纸组件；本地图片和图片网址继续可用。免费组件允许清单保持 29 项内置与 18 项在线。

## 构建与验证

常规 `npm run build` 直接使用本工程已生成资源，不依赖上级原包。开发时重新提取这份固定原包可运行 `npm run prepare:appearance`；不要用其他版本替换输入。

图标编辑资源用 `npm run prepare:icon-editor` 重新提取，输入同样固定为随附的 2.3.13。`tests/icon-editor.test.mjs` 覆盖文字/图片切换、SVG 备份往返、非法内容与运行包依赖边界。`scripts/qa-icon-editor.cjs` 和 `scripts/qa-icon-editor-extra.cjs` 检查真实 UI、裁剪上传、获取图标、窄屏、文件夹、深色主题和自定义颜色。

浏览器检查使用独立测试 profile，会重置测试主页；不要在个人使用中的 profile 执行验收脚本。

- `npm test`：24 项通过，包含新设置的备份往返、非法值校验与原版 UI 构建依赖检查。
- `npm run check`：检查入口、脚本、CSS/字体、默认图标和原版依赖引用。
- `scripts/qa-appearance.cjs`：17 项浏览器检查，覆盖抽屉尺寸、7 页设置、实时更新、刷新、原版字体、深色主题、原版壁纸窗口、JSON 导入导出及 390px 窄屏。
- `scripts/qa-native-workflows.cjs`：12 项原版组件工作流，改为点击原版窗口自身的关闭按钮，验证便签、待办、番茄钟等保存时序。

Google OAuth 沿用既有配置边界：未配置自有客户端 ID 时不能真实授权，JSON 备份可用。本次未新增 Google 授权验证。

实际扩展环境复测：29 项内置卡片和 29 项弹窗全部 ready，原账号相关请求为 0；17 项外观/备份检查通过；另有 6 项最终检查覆盖系统主题同步、壁纸预览刷新、文件夹、网址编辑和删除确认，均无未捕获错误。
