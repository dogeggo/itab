# 当前原版组件宿主

版本：2.0.0；输入原包：本次提供的原版 2.3.13。

## 运行路径

1. 原版 widget/list 或随包 native-catalog 提供目录。
2. original-widgets.js 仅放行已审核的 29 项内置与 18 项在线组件；model.js 和原版宿主再次校验标识。
3. 内置组件由 original/host.html + host.js 加载裁剪后的原版 Vue 卡片或弹窗。原版通用账号弹窗分发器已删除，当前 dialogs 清单只加载允许组件。
   “下一个假期”保留在线详情类型，但主页卡片由同源宿主加载原版 `xiayigejiaqi-icon`。构建的 `nativeCardComponents` 清单单独保留此卡片；宿主只允许它使用 card 模式，不尝试加载不存在的本地详情弹窗。假期列表和更新日期保存在 `nativeData.local` 中，首次无缓存时沿用原版接口请求。
4. src/native-bridge.js 负责当前主页与组件的主题、布局、配置、壁纸、打开/关闭、右键和书签导入。
5. original/data.js 是当前数据接口；原版保存调用直接连接父主页会话，没有浏览器 API 或旧数据库接口仿真。
6. src/storage.js 将 schemaVersion 2 状态保存到独立的 itab-local-v2 数据库；JSON 和 Google Drive 都备份此状态。

## 数据格式

- groups[].items[].config.original.config：原版组件实例配置。
- nativeData.local：组件偏好和卡片摘要的 JSON 文本。
- nativeData.stores.cache：当前带过期时间的缓存、完整待办和番茄钟数据。
- nativeData.stores.notes.items：完整富文本便签，内容使用原版 Markdown 格式。
- nativeData.stores.wallpaper：公开壁纸缓存。

主页的尺寸使用列×行，传入原版卡片时转换为行×列：`2x1 → 1x2`、`1x2 → 2x1`、`4x2 → 2x4`。已有组件保留原来的占位尺寸，不需要重新添加或转换备份格式。

只允许上述三个数据空间。账号凭据和旧便签同步字段被拒绝；旧主页、旧数据库、旧格式备份不读取、不升级、不合并。原版媒体 Worker 原样提取为本地文件，满足 Manifest V3 CSP。

## 已删除的路径

全部本地组件；原版登录、注册、账号存储、会员/支付、云同步、旧便签数据库迁移、旧图标尺寸/组件标识转换、浏览器 API 模拟、localStorage 覆盖、localforage / Dexie 仿真，以及无效的空同步实现。原版依赖通过构建裁剪后随项目提供，运行包不包含被屏蔽的 PDF/AiPPT 模块。

## 原版代码保留范围

原版组件界面和交互业务保留。便签的保存和初始化段改成当前宿主调用；增删、置顶、富文本编辑仍使用原版实现。原版共享框架和第三方库正常的现代浏览器能力检测、外部行情格式解析、网络错误处理仍属于运行依赖，不是旧主页迁移。

18 项在线页面运行在原站的跨域 iframe 内；其内部存储和服务器逻辑不在此工程中，也不进入 Google / JSON 备份。本工程不向它们传递原版账号或 Google 令牌。书签、屏幕录制等浏览器能力使用真实 Chrome API，不支持的网页预览环境不会伪造权限。
