# 图标本地存储（2026-10-03）

网站图标和组件封面改为首次下载后本地持久化。保存成功后，主页、文件夹预览和文件夹窗口直接使用图片内容，刷新页面不再访问原图地址。

## 保存与恢复

- 随包图片和上传图片保持本地使用。
- 已有主页、新增组件和导入备份中的远程图片在后台转换，当前页面的组件实例继续保留。
- 图标编辑器获取的候选图片先查本地缓存；新增或编辑时，远程图片下载成功后才提交。
- 图片以 Data URL 保存到 `itab-local-v2` 的主页状态，完整内容随 JSON / Google Drive 备份。按来源 URL 保存的下载缓存用于复用图片；即使该缓存丢失，已保存的主页和备份仍包含图片内容。
- PNG、JPEG、WebP、GIF、SVG 保留原格式；ICO 等其他可解码图片转为 PNG，最长边限制为 512 像素。下载原图的上限为 2 MB，按响应流检查，单次下载超时为 10 秒。
- 相同 URL 合并请求，跨标签页用 Web Locks 协调；下载、转换和写入最多四项并发。
- 下载过程中修改、删除图标或恢复备份时，不把过期结果写回新图标。保存原来的 `contain` / `cover` 适配方式，避免本地化改变图片布局。

## 无法读取的图标

旧图标遇到离线、错误响应或跨域限制时保留原地址，不删除图片；当前页面记住失败，重绘时不重复尝试下载。该类图标在成功保存到本地之前仍可能需要访问源站。

对于允许展示却禁止跨域读取的图标，在编辑器点击保存时，扩展可通过可选站点权限申请该图片所在域名的读取权限。授权成功后重试下载；未授权或仍无法下载时，编辑器提示上传本地图片，保留当前草稿。清单只声明可选 HTTP/HTTPS 站点权限，实际调用每次仅申请当前图标的域名。

原版 SVG 选择逻辑同时支持本地 Data URL，获取后选择 SVG 时直接使用矢量图片，无需进入位图裁剪。重新提取原版编辑器时也应用同一改动。

组件内部联网内容、壁纸和 Google 账号头像继续使用各自原有的加载方式。
