# iTab 主页复刻执行计划

## 目标与边界

以当前目录的 iTab 2.3.13 扩展为对照，新建独立、可维护、可直接加载的 Manifest V3 浏览器扩展。复刻主页的视觉结构与核心交互：图标、打开方式、搜索栏、时间日期、主题壁纸、布局、备份，以及主页组件。备份改为 Google Drive。原扩展文件保持不变。

不接入原版会员、支付、推广、账号服务；原服务提供的天气、热榜等网络数据使用独立接口或明确的外部入口，不能把演示数据当作实时数据。

## 工程原则

- 主页与配置在离线状态下可用；外部数据错误时给出清楚的状态。
- 设置即时预览并持久化，搜索与网站链接分别遵守打开方式。
- 所有脚本随扩展打包，符合 MV3 CSP，不使用远程执行代码。
- Google OAuth 客户端 ID 必须由使用者自己的 Google Cloud 项目创建；不伪造凭据或登录结果。
- 原版可用的本地壁纸、字体及图标仅按需要复制，并记录来源。
- 尽量使用 Web 标准和少量依赖，避免再次形成无法维护的打包代码工程。

## 验收标准

1. 浏览器新标签页可直接打开复刻主页；页面尺寸、位置、配色及设置交互有原版对照记录。
2. 添加/编辑/删除/排序网站、切换分组、切换布局和调整样式均生效且刷新后保留。
3. 搜索支持引擎选择、自定义引擎、历史记录和打开方式；时间日期与壁纸可独立设置。
4. 主页组件可操作，不仅是静态示意图。
5. 导出的备份能完整恢复；损坏/不兼容备份被拒绝；Google 云备份流程具备真实实现和配置说明。
6. 自动检查与浏览器验收结果如实记录，未实际连接 Google 账号的部分明确标记。
