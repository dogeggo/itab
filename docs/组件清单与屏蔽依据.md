# 组件清单与屏蔽依据

基准：本次提供的原版 2.3.13 发布包及保存的原仓库快照；当前工程版本 2.0.0。仓库没有统一的付费标志，因此使用经代码审计的固定允许清单，未知条目不自动添加。

## 屏蔽与裁剪

| 组件/功能 | 处理 | 依据 |
| --- | --- | --- |
| PDF 转换大师 | 删除目录和随包模块 | 原版转换路径调用 userVipRef.canUse，接入会员次数体系 |
| AiPPT | 删除目录和随包模块 | 原版页面向在线生成器传递账号 token，包含会员订阅入口 |
| videoConvert | 删除旧入口 | 原版导航迁移把它转换成当前 mediaBox；本项目只保留 mediaBox |
| 股票图片识别导入 | 删除上传/粘贴图片入口与处理函数 | 原版要求登录后上传图片并调用识别接口 |
| 壁纸上传、我的收藏 | 删除来源注册、入口和对应组件 | 原版要求账号，使用原站上传/收藏数据 |
| 便签图片上传 | 删除图片上传菜单及粘贴/拖入上传插件 | 原版用账号标识生成上传路径并访问原站 OSS |
| 原版账号、会员、支付、同步、统计身份 | 删除代码及调用 | 不属于当前主页功能，当前备份只走 Google / JSON |
