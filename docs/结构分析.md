# 原插件结构与复刻方案

## 原插件结构

分析对象为用户提供的 iTab **2.3.13** 发布目录。目录中没有 `package.json` 或原始 Vue 单文件组件，主体是已经编译、压缩的 JavaScript/CSS。读取时未改写原插件的入口、后台或资源。

| 路径 / 模块                                           | 职责与分析结论                                                                                |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `manifest.json`                                       | Manifest V3；通过 `chrome_url_overrides.newtab` 指向 `newtab.html`；后台为 `background.js`。  |
| `newtab.html`、`index.html`                           | 共享主页脚本 `chunks/main-pR7HcDL9.js`。                                                      |
| `js/init.js`                                          | Vue 挂载前读取 `localStorage.baseConfig.wallpaper`，先绘制背景，减少白屏。                    |
| `chunks/main-pR7HcDL9.js`                             | 时钟、搜索、主页图标、文件夹、网格、上下文菜单等主页逻辑。                                    |
| `chunks/stocksCache-CNvbf2yR.js`                      | 名称虽然带 stocks，但包含核心默认配置、Vue 共享状态、本地存储、导航分组、图标排布和迁移逻辑。 |
| `chunks/defaultNavConfig-B7uRQ5vb.js`                 | 内置六组导航及组件；在线运行会用服务端返回的数据补充/替换。                                   |
| `chunks/icon-CRwW-IH5.js`                             | 图标大小、圆角、透明度、X/Y 间距、名称、名称颜色、网格最大宽度。                              |
| `chunks/open-CPcHO033.js`                             | 搜索结果、网站图标分别选择当前页或新标签页打开。                                              |
| `chunks/search-SQmPP6kd.js`                           | 搜索栏显示、高度、圆角、透明度、历史和全局搜索设置。                                          |
| `chunks/time-BSnPnxuW.js`                             | 时间显示、月日、星期、农历、24 小时、秒、粗体、字体、字号及颜色。                             |
| `chunks/layout-V2nQcA5Q.js`                           | 组件/极简视图；底部一言开关。                                                                 |
| `chunks/staleAssetReload.lazy-DksV6goU.js`            | 包含大量主页组件，动态加载天气、日历、倒数日、备忘录、下班倒计时等。                          |
| `chunks/store-BkQ4EtcH.js`、`store-DQmDOK8m.js`       | 备忘录和待办的独立状态/数据逻辑。                                                             |
| `chunks/backup-DZ4qT5K_.js`、`public-api-DajUmvL1.js` | 原账号云备份、本机历史节点、分项导入导出和同步。                                              |
| `background.js`                                       | 原扩展的右键、快捷键、全局搜索、通知等后台行为；复刻只保留所需入口。                          |
| `assets/`、`setting/`、`webfont/`、`weather/`         | 编译 CSS、设置图标、时间字体、天气图标等。                                                    |

原版框架是 Vue，使用 Vite/WXT 风格的拆包、Element Plus、VueUse、dayjs、lodash 等。无需把这些压缩模块整体搬到新工程：独立主页用原生 ES Modules 与浏览器 API 就可以完成；1.0.1 已删除 PDF 库，无 npm 运行依赖。

## 主页数据与布局

原版主要用 `localStorage` 的 `baseConfig`、`navConfig`、`menuActiveId` 保存设置与导航。组件数据还使用 IndexedDB。

`navConfig` 是分组数组，每个分组的 `children` 可以是网站图标、组件或文件夹；组件与图标共用网格。原版尺寸字段 `2x4` 表示高 2、宽 4，新工程显式使用宽 × 高的 `4x2`。

默认参数从原版代码中提取并留档于 `original-default-config.json`：

- 图标 60px、圆角 18px、横纵间距 30px；名称 12px 白色。
- 网格最大宽度 1350px，左右预留 50px；1440px 宽度时网格实际宽度 1230px、左边距 105px。
- 时间 70px，HarmonyOS Sans；默认显示日期、星期和农历。
- 搜索框 600px × 46px，圆角 23px，背景透明度 0.5。
- 左侧栏 50px，组件模式，底部一言；点击时间切换极简模式。
- 设置为 **450px 右侧抽屉**，页面保持可见以即时预览样式。

除内置配置外，还留存实际运行后的匿名默认导航 `original-live-state.json`，因为在线运行多出 PDF 卡片、WorkBuddy、通义千问、携程等入口。新工程以这一状态还原主页顺序；1.0.1 按用户要求移除本地 PDF / AiPPT 入口。

原版网页预览直接运行时会因缺少扩展 `chrome.runtime` 报错。视觉对照使用只在测试页面注入的最小扩展 API 适配，并未修改原包；复刻工程则分别验证了网页预览与真实扩展加载。

## 持久化与备份逻辑

数据保存在 IndexedDB 的 `itab-local/data`：`state` 为完整主页，`snapshots` 为最近五个历史节点，天气/榜单为独立缓存。上传壁纸与图标转换为 data URL 并随备份保存，内置资源用相对路径引用。

备份文件包含 `app`、`version`、`createdAt`、`state`。恢复先检查版本、分组/图标、URL 协议、ID 唯一性、设置范围及组件数据；通过后先保存旧状态快照，再写入新状态。Google 访问令牌由浏览器 identity API 管理，不写入备份。

Google 只申请 `drive.appdata`，备份位于 `appDataFolder`。网页预览不模拟 Google 登录，真实扩展未配置客户端 ID 时提供准确提示。

## 与原版的具体差异

这是围绕用户指定范围独立实现的主页复刻，尚不能称为所有细节和后台能力的完全相同复制。

- 原版账号、订阅、支付和推广不接入；网站跳转尽量替换为官方直接地址。
- Google Drive 替代原账号云备份；需要使用者创建 OAuth 客户端，详见 `Google备份配置.md`。
- 天气改用 Open-Meteo，可搜索城市、刷新，缓存 30 分钟；不复刻原版完整空气质量和天气详情系统。
- 百度榜单和科技榜使用公开实时数据；微博、抖音提供官方榜单入口，不冒充实时内嵌列表。
- 电影日历是可编辑的本地电影卡片，未接入原版每日推荐后台。
- 本地 PDF 和 AiPPT 已删除；原版仓库保留这两项但当前标记待适配。原版仓库与 18 类在线入口接入情况见 `原版组件复用分析.md`。
- 下班倒计时实现工作时间与周末状态；原版工资、发薪、节假日工资统计未作为已实现功能显示。
- 不包含浏览器所有页面上的悬浮全局搜索、商城、媒体工具箱及不在主页范围内的扩展功能。

上述差异在运行说明和验收记录中保留，避免将界面相似程度与后台服务等价混为一谈。
