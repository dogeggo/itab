# 原插件结构与复刻方案

## 原插件结构

分析对象为用户提供的原版 **2.3.13** 发布目录。目录中没有 `package.json` 或原始 Vue 单文件组件，主体是已经编译、压缩的 JavaScript/CSS。读取时未改写原插件的入口、后台或资源。

| 路径 / 模块                                           | 职责与分析结论                                                                                |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `manifest.json`                                       | Manifest V3；通过 `chrome_url_overrides.newtab` 指向 `newtab.html`；后台为 `background.js`。  |
| `newtab.html`、`index.html`                           | 共享主页脚本 `chunks/main-pR7HcDL9.js`。                                                      |
| `js/init.js`                                          | Vue 挂载前读取 `localStorage.baseConfig.wallpaper`，先绘制背景，减少白屏。                    |
| `chunks/main-pR7HcDL9.js`                             | 时钟、搜索、主页图标、文件夹、网格、上下文菜单等主页逻辑。                                    |
| `chunks/stocksCache-CNvbf2yR.js`                      | 名称虽然带 stocks，但包含核心默认配置、Vue 共享状态、本地存储、导航分组、图标排布和迁移逻辑。 |
| `chunks/defaultNavConfig-B7uRQ5vb.js`                 | 内置六组导航及组件；在线运行会用服务端返回的数据补充/替换。                                   |
| `chunks/icon-CRwW-IH5.js`                             | 图标大小、圆角、透明度、X/Y 间距、名称、名称颜色、网格最大宽度。                              |
| `chunks/open-CPcHO033.js`                             | 搜索结果、网站图标分别选择当前页或新标签页打开。                                              |
| `chunks/search-SQmPP6kd.js`                           | 搜索栏显示、高度、圆角、透明度、历史和全局搜索设置。                                          |
| `chunks/time-BSnPnxuW.js`                             | 时间显示、月日、星期、农历、24 小时、秒、粗体、字体、字号及颜色。                             |
| `chunks/layout-V2nQcA5Q.js`                           | 组件/极简视图；底部一言开关。                                                                 |
| `chunks/staleAssetReload.lazy-DksV6goU.js`            | 包含大量主页组件，动态加载天气、日历、倒数日、备忘录、下班倒计时等。                          |
| `chunks/store-BkQ4EtcH.js`、`store-DQmDOK8m.js`       | 备忘录和待办的独立状态/数据逻辑。                                                             |
| `chunks/backup-DZ4qT5K_.js`、`public-api-DajUmvL1.js` | 原账号云备份、本机历史节点、分项导入导出和同步。                                              |
| `background.js`                                       | 原扩展的右键、快捷键、全局搜索、通知等后台行为；复刻只保留所需入口。                          |
| `assets/`、`setting/`、`webfont/`、`weather/`         | 编译 CSS、设置图标、时间字体、天气图标等。                                                    |

原版框架是 Vue，使用 Vite/WXT 风格拆包、Element Plus、VueUse、dayjs、lodash 等。当前工程复用原版免费组件、7 个原版设置页面及对应运行依赖，主页宿主使用独立 ES Modules。原版账号、会员、云同步、旧主页迁移、PDF 和 AiPPT 不进入当前运行包。

## 当前结构

| 路径 | 职责 |
| --- | --- |
| src/app.js、settings.js、styles.css、appearance.css | 主页宿主、原版外观容器与当前备份 |
| original/appearance/、src/appearance-model.js | 原版设置页面、字体、图标与设置数据映射 |
| src/clock.js | 主页时间日期 |
| src/original-widgets.js、widget-store.js | 允许清单校验、原版仓库及组件入口 |
| original/host.js、registry.js、chunks/ | 原版卡片、弹窗和当前宿主 |
| src/native-bridge.js、native-data.js、original/data.js | 当前组件数据接口与格式校验 |
| src/storage.js、drive.js | 当前项目保存、恢复与 Google 备份 |
| scripts/prepare-native.mjs、refine-native.mjs | 针对输入原包的导入和依赖裁剪 |

详细数据路径见 [当前组件宿主](原版组件复用分析.md)。工程不包含本地重写的小组件和旧版本迁移代码。
