## 复测方式

```powershell
npm run check
npm test
npm run build
```

浏览器操作脚本保存在 `scripts/qa-main.cjs`、`qa-widgets-backup.cjs`、`qa-layout.cjs`、`qa-extension.cjs`、`qa-original-widgets.cjs`、`qa-original-tools.cjs`。它们使用 Playwright CLI 的 `run-code --filename` 执行；会修改测试浏览器内的主页数据，应使用独立测试 session/profile。`qa-main` → `qa-widgets-backup` → `qa-layout` 是相互衔接的验收顺序。

JSON 等测试文件位于 `output/playwright`，不包含在扩展安装包中。测试中产生的用户状态也不会打入 `dist`。
